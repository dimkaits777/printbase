### Шаг 2: Добавьте видео баннер

**Куда:** `/workspace/assets/video/hero-banner.mp4`

**Требования к видео:**
- Формат: MP4 (H.264 codec)
- Разрешение: 1920x1080 (Full HD)
- Длительность: 10-30 секунд
- Размер: до 5 MB для быстрой загрузки
- Звук: не нужен (видео будет без звука)

**Идеи для видео:**
- Таймлапс 3D печати

**Альтернатива:** Если нет видео, создайте статичный постер `assets/images/hero-poster.jpg`

### Шаг 3: Обновите товары в products.js

**Файл:** `/workspace/js/products.js`

#### Вариант А: Редактировать напрямую в файле

Откройте `js/products.js` и измените массив `products`:

```javascript
{
    id: 'уникальный-id',
    name: 'Название товара',
    category: 'toys', // или 'home-decor', 'dragons', 'jewelry'
    price: 19.99,     // цена в долларах
    description: 'Описание товара на английском',
    image: 'assets/images/products/filename.jpg',
    badge: 'Bestseller', // или 'New', 'Popular', '' (пусто)
    affiliateLink: 'https://www.creativefabrica.com/3d-printing/ref/ВАШ_ID/'
}
```

#### Вариант Б: Загрузить из CSV файла

1. Создайте файл `products.csv` со структурой:
```csv
id,name,category,price,description,image,badge,affiliateLink
toy-001,Articulated Dragon,toys,12.99,Flexible dragon toy,assets/images/products/dragon.jpg,Bestseller,https://...
```

2. В `main.js` используйте функцию `loadProductsFromCSV()` (уже есть в коде)

#### Ваша партнёрская ссылка Creative Fabrica

Замените во всех товарах:
```
https://www.creativefabrica.com/3d-printing/ref/20531415/
```
на вашу ссылку из партнерской программы Creative Fabrica.

## 🔧 Дополнительные настройки

### Добавление новых товаров

Просто добавьте новый объект в массив `products` в `js/products.js`:

```javascript
{
    id: 'new-product-001',
    name: 'New Product Name',
    category: 'toys',
    price: 24.99,
    description: 'Description in English',
    image: 'assets/images/products/new-product.jpg',
    badge: 'New',
    affiliateLink: 'https://your-affiliate-link.com'
}
```

### Добавление новой категории

1. В `index.html` добавьте новую секцию:
```html
<section id="new-category" class="category-section">
    <div class="container">
        <div class="section-header">
            <h2><i class="fas fa-icon"></i> CATEGORY NAME</h2>
            <p>Description</p>
        </div>
        <div class="products-grid" id="new-grid" data-category="new-category">
        </div>
    </div>
</section>
```

2. В `js/main.js` добавьте обработку категории
3. В `js/products.js` добавьте товары с `category: 'new-category'`
4. В меню навигации добавьте ссылку

### Оптимизация скорости

1. **Сжатие изображений:** Используйте [TinyPNG](https://tinypng.com) или [Squoosh](https://squoosh.app)
2. **Конвертация в WebP:** Конвертируйте JPG в WebP для лучшей компрессии
3. **Минификация CSS/JS:** Используйте онлайн инструменты
4. **CDN:** Подключите файлы через CDN

## 📊 UTM метки для отслеживания

Сайт автоматически добавляет UTM метки к партнёрским ссылкам.

### Как использовать:

1. Посетитель приходит по ссылке:
   ```
   https://yoursite.com/?utm_source=pinterest&utm_medium=social&utm_campaign=spring_sale
   ```

2. Метки сохраняются в sessionStorage

3. При клике на товар автоматически добавляются:
   ```
   https://creativefabrica.com/...?utm_source=pinterest&utm_medium=social&utm_campaign=spring_sale
   ```

### Где создавать ссылки:

- [Google Campaign URL Builder](https://ga-dev-tools.google/campaign-url-builder/)
- Параметры: source, medium, campaign, term, content

## ❓ Частые вопросы

### Q: Как изменить цены на рубли?
A: В `products.js` измените значения `price`. Для конвертации используйте текущий курс.

### Q: Можно ли принимать оплату напрямую?
A: Да, но нужно интегрировать платёжную систему (Stripe, PayPal). Сейчас сайт работает по партнёрской модели.

### Q: Как добавить корзину покупок?
A: Потребуется бэкенд или использование готовых решений (Snipcart, Ecwid).

### Q: Сайт не отображается правильно?
A: Проверьте:
- Все ли файлы на месте
- Правильные ли пути к изображениям
- Нет ли ошибок в консоли браузера (F12)

### Q: Как перевести сайт на русский?
A: Замените текст в `index.html` и `products.js` на русский. Meta теги тоже обновите.
